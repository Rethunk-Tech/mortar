Start modding Mimesis

  1. Download Mortar for Linux or Windows and open it.
  2. Pick Mimesis. Mortar installs MelonLoader and makes your first profile.
  3. Open Browse, add the mods you want, and press Play. Each profile keeps its own mods and settings.

Share a profile

A profile for Mimesis shared from Mortar is a link to mortar.rethunk.tech/mimesis/p. Whoever opens it sees the mod list and imports it into Mortar in one click. The whole profile is inside the link, so nothing is uploaded anywhere.
