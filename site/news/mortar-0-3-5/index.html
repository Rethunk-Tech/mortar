Mortar 0.3.5 · October 17, 2026

MelonLoader and 95 more games

283 games in all: MelonLoader, Nexus Mods games that read their own mod folder, and seven new loaders.

What changed in 0.3.5

New

Games

  • 95 more games, 283 in all
  • MelonLoader, with 39 games: BONELAB, BONEWORKS, Schedule I, RUMBLE, Gang Beasts, Bloons TD 6 and more
  • 24 Nexus Mods games whose mods go in a folder the game reads itself: The Witcher 3, Cyberpunk 2077, 7 Days to Die, Blade & Sorcery, Monster Hunter: World, both Kingdom Come games, Hogwarts Legacy, Stellar Blade, S.T.A.L.K.E.R. 2 and more
  • New loaders for Titanfall 2 (Northstar), Hades II and Risk of Rain Returns (ReturnOfModding), WEBFISHING (GDWeave), Balatro (Lovely), Broforce (Unity Mod Manager) and Scrap Mechanic (Rivet)
  • 25 more BepInEx games, among them Among Us, V Rising, Core Keeper, Lost Skies, H3VR, GTFO, ULTRAKILL, both Subnautica games, Timberborn and Crab Game
  • BepInEx mods that install beyond BepInEx/plugins (H3VR's Sideloader, ULTRAKILL's UMM Mods, Subnautica's QMods) land where the game reads them
  • BepInEx 6 Mono packs, legacy IL2CPP packs, packs laid out at the zip's top and packs that load through version.dll all install

Mods and browsing

  • Every Browse card shows the mark of the site the mod installs from
  • Show › Obsolete and Broken can Flag a mod with a warning before its name instead of graying it out

Interface and settings

  • Grow game rows on hover can be turned off, so Game select's rows stay still

Fixed (4)
  • LethalModDataLib's .moddata files belong to their Lethal Company save slot instead of showing as extra saves
  • Zips whose folder names use Windows backslashes extract
  • Browse card authors and stats are readable in light mode
  • Searching Settings for "Personal API key" finds the Nexus key

The Linux AppImage and portable program need glibc 2.38 or newer (Ubuntu 24.04, Debian 13, Fedora 39 or later); older systems use the Flatpak.
