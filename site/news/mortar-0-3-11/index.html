Mortar 0.3.11 · October 22, 2026

Startups explained, errors traced

Each phase of a start and its slowest mods, errors traced to the Harmony patch that threw, and imported profiles keep their local mods.

What changed in 0.3.11

New

Linux and Windows

  • The AppImage runs on Linux Mint 21 and Ubuntu 22.04 (glibc 2.35 and newer)
  • The Flatpak keeps up with the other builds: switching a mod on or off takes a tenth of a second instead of a second, and the window opens sooner
  • On Windows the window opens straight away, without the long PowerShell pass some PCs saw before it
  • Use the system title bar, in Settings › Appearance, for desktops with their own window decorations

Importing and sharing

  • Gale profiles and r2modman or Gale codes bring the mods that were added from disk, as local mods, and the preview warns before a code's own program files install
  • In the import preview a mod's name opens its page, full names show and can be copied, and the whole tile shows what comes in

Mods and profiles

  • Local mods are marked in cards and the list (Mark local mods, on by default)
  • A selected card is tinted as well as outlined
  • The profile actions menu is grouped under headings and opens the profile folder
  • A mod's Needs and Used by include the libraries its plugins ask for

Performance and diagnostics

  • Performance opens on two cards, Startup and In game, with each phase named on the bar and the six slowest mods with their share of mod time
  • In game measuring starts on any launch, not only a measured one (Mortar BepInEx Bridge 0.3.2)
  • mortar.log times each step of Mortar's start, and Restart and record startup profile in the Mortar menu records the first 30 seconds for a bug report
  • Errors while running say which Harmony patch threw, on what, and at which source line
  • A crash names the native function the game died in, from Unity's and Microsoft's symbol servers

Games

  • Cities: Skylines II cities are listed and backed up per profile

Fixed (8)
  • After a Steam launch, Play now and Measure no longer stay greyed out once the game has closed
  • A library only a local mod's plugin asks for is no longer offered for removal
  • A game opened only for its setup page is no longer listed under Recently played
  • An error while running links to its own guide section
  • A program renamed with .old is refused in an imported profile, like any other program
  • The Flatpak on NVIDIA's proprietary driver gets the same rendering workaround as the other builds
  • Link previews of mortar.rethunk.tech no longer run words together
  • A card no longer shows a stray separator for a mod with no version
