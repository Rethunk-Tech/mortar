Mortar 0.5.0 · November 3, 2026

mod.io and 32 more games

mod.io is a source with its own sign-in, Baldur's Gate 3 and Bannerlord get a Load order tab, Release everywhere uploads to every site at once, 32 games are new, and a list of fixes.

What changed in 0.5.0

New

  • mod.io is a source: sign in with a read-only token in Settings › Accounts to browse and install from it. Blade & Sorcery, S.T.A.L.K.E.R. 2, Baldur's Gate 3, Timberborn, BONELAB, Gladio Mori, Deep Rock Galactic and Core Keeper use it, and share links carry mod.io files
  • 32 more games, among them Baldur's Gate 3, Mount & Blade II: Bannerlord, Core Keeper, Dome Keeper, Resonite, Brotato, Papers, Please, Disco Elysium and Ancient Dungeon VR
  • A Load order tab for Baldur's Gate 3 and Mount & Blade II: Bannerlord shows the order the game will use and the issues in it; Baldur's Gate 3's can be reordered
  • Release everywhere in Develop packs the project once and uploads to every site that is ready, with progress per site and a retry
  • Develop's Release creates the project's GitHub release from its tag and attaches the package
  • Develop keeps a project's Thunderstore dependencies and its development profile's mods in step, and Edit project picks categories from Thunderstore's list
  • Share, Nearby computer sends a development profile to a paired computer for a co-op test, building what changed first
  • Upload a modpack to Thunderstore from its export dialog, with its categories picked from the community's list
  • A profile can run its own game version, and Get an older version lists the past Steam builds Mortar has seen
  • Core Keeper and other BepInEx 6 IL2CPP games install and launch their packs
  • Vintage Story profiles can run the dedicated server with the same mods
  • A mod that is one zip file installs as it is
  • Settings › General › Code editor picks what Open in editor and compiler errors open: every installed version of VS Code, VSCodium, Cursor, Rider and Visual Studio, the project's default app, or any other program
  • Polish is open for translation on Weblate

Changed (6)
  • The Mortar menu is shorter: Source code and the startup profile moved to Settings › About
  • Used by lists each dependent once and opens a row's own dependents on click
  • New mod takes four steps, and its last one no longer scrolls
  • Grid cards in Mods and Browse show their figures with icons
  • A share's mod list says how many mods repeat another's name and version
  • Settings, Develop, Console, profile, game and download text is tighter

Fixed (15)
  • The update banner takes room from the page, so Play no longer slides under the task bar (#15)
  • Decompiling and previewing the game's code works when the tool is a command file in a folder with a space on Windows (#16)
  • Open in editor does something on Windows when the editor is a command file in a folder with a space
  • Build and Build all install content projects, and a project's chip says whether it is in the profile
  • A project's start-up figure says when it was measured
  • Browse details and Change version show the sign-in prompt without asking Nexus while signed out
  • A send to a nearby computer right after a start rebuilds only what changed
  • A new updates notice replaces the one on screen instead of stacking
  • A game started from a profile's own game folder is found as running
  • Install missing in Develop installs into the project's development profile
  • A profile named default no longer claims the files of default-2
  • A modpack upload remembers its team without changing the modpack's author
  • Baldur's Gate 3's main campaign is listed first, as BG3 Mod Manager does
  • A game the signed catalog dropped is no longer found through the bundled one
  • Mod versions up to and other profile fields are named for screen readers
