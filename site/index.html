Features

Built for big mod lists

Hundreds of mods, several farms, friends on the same pack. Mortar is made for that setup, not just the first five mods.

A profile for every playthrough

Keep a vanilla-plus farm, a Stardew Valley Expanded run and a co-op pack side by side. Each profile has its own mods, settings and launch options, and switching is one click.

  • Install, update and roll back mods per profile
  • Updates show the changelog before you take them
  • Start new profiles from templates
  • Save backups on a schedule, with a timeline per farm

Know what broke before you launch

Mortar reads every mod's manifest and content packs, then explains problems in plain words: missing dependencies, outdated versions and which mod wins each content conflict.

  • Missing dependencies found and queued for you
  • Content conflicts explained file by file
  • One-click fixes: switch a mod off or make a pack win

See what slows your startup

With the bundled SMAPI bridge, Mortar measures how long the game takes to reach the title screen and what each mod costs along the way, so a slow load has a name.

  • Time to title screen, compared with the last launch
  • Per-mod startup and in-game cost
  • Game console and logs inside Mortar

Looks the way you like

Dark or light, eight accent colours, and your own image, your desktop wallpaper or a solid colour behind the window.

FAQ

Questions

Is Mortar free?

Yes. Mortar is free and open source under the AGPL-3.0 licence, with no account, ads or tracking in the app.

Do I need Nexus Mods Premium?

No. With a free Nexus account you click Mod Manager Download on a mod's page and Mortar takes it from there. Premium members can also download from inside Mortar.

Does Mortar host mod files?

No. Every mod downloads from its own page on Nexus Mods or GitHub, so authors keep their downloads and endorsements. The one exception is sending a profile to another of your own computers on your network.

Which games does it support?

Stardew Valley, from Steam (including Flatpak Steam), GOG, Heroic and Lutris. Mortar is built for more than one game, and Lethal Company support is planned for a later release.

Windows says it protected my PC. Is that normal?

Yes. The Windows builds are not code-signed yet, so SmartScreen warns the first time. Choose More info, then Run anyway. The source and the release builds are public on GitHub.

How do I know a download is genuine?

Every release is built from the public source by GitHub Actions. The package repositories, Flatpak repository and each release's checksums are signed with the Mortar packages key, and Mortar checks a signature on every update before installing it. The code signing policy shows how to check a file yourself.

What happened to Concrete?

Concrete, our Lethal Company mod manager, is archived. Mortar is its successor, rebuilt from scratch for several games.

Where do I report a bug?

Use Report a Mortar bug in the app's help menu, which attaches diagnostics, or open an issue on GitHub.
