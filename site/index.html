Features

Built for big mod lists

Hundreds of mods, several playthroughs, friends on the same pack. Mortar is made for that setup, not just the first five mods.

A profile for every playthrough

Keep a vanilla-plus farm, a Stardew Valley Expanded run and the pack your Lethal Company crew plays side by side. Each profile has its own mods, settings and launch options, and switching is one click.

  • Install, update and roll back mods per profile
  • Updates show the changelog before you take them
  • Start new profiles from templates
  • Freeze a profile so its mods stay on the versions you have
  • Pick the version to install, not only the newest
  • Star the mods and profiles you reach for most
  • Save backups on a schedule, with a timeline per save

Stardew Valley on SMAPI

Mortar installs SMAPI and keeps it up to date, and handles a profile of hundreds of mods with cover art, groups and filters. Each game keeps its own loader, mod sites and settings, so switching games is one click on Game select.

  • Click Mod Manager Download on Nexus Mods and the mod lands in the right profile
  • Import Nexus collections with their FOMOD choices
  • SMAPI options set for the game or for one profile

Lethal Company, Valheim and more on BepInEx

Mortar installs the BepInEx pack each game needs and keeps every Thunderstore package in the profile, not the game folder. At launch it places BepInEx beside the game and takes it back when the game exits. On Linux, Valheim's native build runs modded without Proton.

  • Plugin settings stay with the profile and travel when you share it
  • Plugins that failed to load or ship twice show up in Problems
  • Import your r2modman or Gale profiles, or export a Thunderstore modpack
  • If one Thunderstore download server fails, Mortar tries the next
  • Valheim and Risk of Rain 2 dedicated servers get their own profiles, which can take a client profile's mods
  • Copy the host's mod list for friends to check against theirs, in Stardew Valley, Thunderstore games and Vintage Story

Every mod site in one search

Browse searches Nexus Mods, Thunderstore, CurseForge, Modrinth, GitHub and the Vintage Story Mod DB at once, whichever the game uses. Add a Thunderstore package and the packages it depends on come with it.

  • Filter by category, sort by downloads or by last update
  • Mods the profile already has are marked
  • Every download comes from the mod's own page
  • Hide a mod, or everything by one author, from Browse
  • Modpacks, translations and cheats start in the exclude filter, one click to remove

Know what broke before you launch

Mortar reads every mod's manifest, Content Patcher packs and the loader's log, then explains problems in plain words: missing dependencies, outdated versions and which mod wins each content conflict.

  • Missing dependencies found and queued for you
  • Content conflicts explained file by file
  • One-click fixes: switch a mod off or make a pack win
  • After a crash, the mod whose code was running is named, in BepInEx, MelonLoader, Vintage Story and SMAPI games

See what slows your startup

In Stardew Valley, the bundled SMAPI bridge lets Mortar measure how long the game takes to reach the title screen and what each mod costs along the way, so a slow load has a name.

  • Time to title screen, compared with the last launch
  • Per-mod startup and in-game cost
  • Game console and logs inside Mortar

Play from Steam Deck Game Mode

Add a profile to Steam and start it from Game Mode like any other game. Mortar stays out of sight while the game starts, shows a dialog only when something needs an answer, and closes with the game so Steam counts your playtime.

  • A gamepad moves focus, confirms, goes back, switches tabs and plays
  • Larger touch and gamepad targets, laid out for the Deck's 1280×800 screen
  • Diagnostics say how launching works in Desktop Mode and in Game Mode

Your profiles on all your PCs

Pair two of your own computers with a short code. A profile you send from one to the other arrives with its mod files, from every source, so nothing downloads twice. No account is involved.

  • Nearby computers are found on your local network
  • The code works once, for five minutes
  • An unpaired computer still gets the profile and downloads each mod

Scanned before it installs

Every mod is checked by your antivirus after it is unpacked and before it reaches your game: Windows' own scanner, ClamAV, or a command of your choice.

Companions

Works with your browser and your game

Two optional add-ons, both open source, both installed from inside Mortar.

Browser extension

Marks Nexus Mods and Thunderstore package pages with what your profile already has and hands downloads and installs to Mortar. For Firefox, Chrome, Edge and other Chromium browsers.

About the extension · mortar-browser-extension

Game bridge

A small mod Mortar adds to each profile. In Stardew Valley it runs console commands sent from Mortar, exposes Generic Mod Config Menu settings, records startup timings and drives an overlay for streaming. In Lethal Company and Valheim it tells Mortar which plugins the running game loaded.
