Changelog

What changed in each release, newest first. The app shows the same notes in What's new after an update.

0.3.4 2026-10-17

New

Games

  • 136 more Thunderstore games: 104 on BepInEx 5, and 32 Unity IL2CPP games (Cat Mail Co. among them) on the shared BepInEx 6 pack
  • BepInEx 6 IL2CPP games get the game's Unity base libraries with the loader, so the first start needs no network
  • Each game, or each profile, can choose which of Steam's Proton builds runs its Windows copy outside Steam
  • Game select's group headings count their games

Mods and browsing

  • Mortar records whether you asked for each mod or it came in for another one (Explicit or Implicit): group, sort and filter by it, mark a mod either way, and show implicit mods in place, nested under the mods that need them, or hidden
  • A profile made before this offers once to mark its libraries, frameworks and tilesheet packs implicit, and Review… lists why each was picked
  • Removing or switching off mods offers to remove or switch off the libraries only they needed
  • Saved groups replace bundles: save a group to your library and add it to any profile
  • A BepInEx mod's other text files (YAML, TOML, XML, INI, JSON and TXT) open in the Config page for editing
  • A tidier details sidebar, and the group header at the top stays in view while the list scrolls

Profiles and sharing

  • A share can leave out libraries and supporting mods and name only the mods you chose; links and .mortar files carry each mod's install reason, pin and groups
  • The import preview shows the mods a share marks as dependencies
  • A profile row counts the mods you chose beside the total
  • A screenshot can become the profile's cover

Problems and diagnostics

  • Cleanup lists dependencies no switched-on mod needs any more
  • A mod that needs a newer game version than you have shows as Broken, Vintage Story's included

Downloads and updates

  • A simpler update review: one Update button per mod, library updates last under Libraries, and a one-row footer
  • When smapi.io stops answering, the offline banner says so, and it clears when smapi.io answers again

Fixed

Mods and browsing

  • Large profiles are much quicker: switching a mod, filtering, opening the list or grid, Browse search and Settings search redraw a fraction of what they did
  • Switching, pinning or noting a mod keeps its details open and your selection
  • The details panel follows the selected mod again
  • Updating or rolling back a mod keeps it in its groups

Problems and diagnostics

  • Cleanup no longer offers to remove a mod a switched-on mod needs, whether its manifest, its Nexus page, a content condition or the images it changes say so

Profiles and sharing

  • A .mortar file carries the profile's groups whether or not it carries notes, and restoring a zip backup restores them

Launching and loaders

  • Mods for an IL2CPP game get the BepInEx 6 the catalog names, not BepInEx 5
  • Bridge features are offered only for games Mortar has a bridge for
  • On Linux, whether WebKit's DMA-BUF renderer is turned off now follows the installed graphics drivers, not PRIME offload
  • Game select no longer reloads every game's run history in a loop

Interface and settings

  • No more message codes in place of text, such as the one that stood in for "4 updates ready"
  • Every popover is solid, the Saves backups menu included
  • The Mods page callouts match the update bar's height

0.3.3 2026-10-16

New

Games

  • Vintage Story: Mortar finds the copy its installer or Flatpak put in place, browses and installs mods from the Vintage Story Mod DB (and Nexus and GitHub), names each mod from its modinfo.json, fetches the mods each one requires, and turns them on for the length of each launch
  • The Mod DB's 1-click install button can open in Mortar: turn on Handle Vintage Story Mod DB links in Settings › Downloads
  • Each Vintage Story profile keeps its own mod settings (ModConfig), and the Config page edits them
  • A game no store has art for shows art from its own install
  • On Linux, a Windows game outside Steam, such as a copy in a folder you chose or one Heroic or Lutris installed, runs through a Proton version your Steam already has, in a prefix Mortar keeps for it
  • Settings › Launchers lists launchers that only run on Windows, and a row for games found where their own installer or Flatpak put them

Saves

  • Vintage Story worlds show their name, play style, play time and the game version that last saved them
  • A Vintage Story world lists the mods it was played with that the profile lacks, and installs each from the Mod DB
  • The world backups Vintage Story makes itself (Modify World and /genbackup) are listed under each world and restore like Mortar's own
  • A Vintage Story world's minimap is backed up and restored with it

Interface and settings

  • A Screenshots tab shows the game's own screenshots and, for a Steam game, the ones Steam takes, newest first, full size on a click
  • Browse cards put Add under the mod's picture, so the name, author, summary and stats get the card's width and read apart

Profiles and sharing

  • Vintage Story Mod DB mods travel in share links, sends to your other computers and the share page

Launching and loaders

  • The Console shows Vintage Story's own log while it runs, and a run that crashes keeps the game's crash report

Fixed

Saves

  • Restoring a save no longer leaves the current save's leftover files beside it, which could undo a Vintage Story restore
  • Saves lists every game's saves without the internet; only Stardew Valley's mod matching needs it

Launching and loaders

  • Mortar finds your Steam account on current Steam clients, so Steam launch options, shortcuts and screenshots work again
  • mortar.log keeps the startup lines that are the only trace of a WebView2 failure

Interface and settings

  • On Linux laptops with an NVIDIA graphics card beside an AMD or Intel one, Mortar no longer renders at a crawl: it keeps WebKit's fast renderer unless it is running on the NVIDIA card
  • Menu items no longer say "Stop the game to change mods." when no game is running
  • Performance's Where the time goes is one stacked bar again, with each phase's time beside its colour
  • Buttons beside a text field are as tall as the field
  • The Nexus key and the browser extension steps sit in their setting rows

0.3.2 2026-10-16

New

Interface and settings

  • Animated backgrounds: an animated GIF, WebP or PNG plays behind Mortar, and holds still when Reduce motion is on or while a game is running
  • Settings › Appearance says when a background image is large enough to cost memory and GPU, and suggests WebP
  • What's new groups each release's changes by area, with a New or Fixed label on every line, and after an update that skipped versions it also shows each release you missed
  • Bottles shows its own icon in Settings › Launchers

Saves

  • A save's backups also list the copies the game keeps itself, Valheim's automatic world backups and The Sims 4's rollback copies, and restore them like Mortar's own

Games

  • Games installed through the Epic Games Launcher on Windows are found, and Play starts them through the launcher: Risk of Rain 2, Enter the Gungeon, Outward and Totally Accurate Battle Simulator
  • On Linux, Mortar also lists those games when Heroic installed them from Epic
  • Games installed through the Xbox app on Windows are found: Valheim, Inscryption and Bomb Rush Cyberfunk
  • Setting up a game that no launcher found offers any copy Mortar finds in your Desktop, Downloads or Games folders before you pick a folder yourself

Problems and diagnostics

  • A bug report names the build beside the version, and mortar.log starts with the version, build and platform

Mods and browsing

  • Browse cards can show downloads, endorsements, likes or stars, file size, version and last updated under the summary: tick the ones you want under Show › Card details
  • Card details show file size for Nexus Mods and Modrinth mods too, as for Thunderstore and CurseForge
  • The Mods tab's cards show the same Card details: endorsements, downloads, size on disk and last updated

Fixed

Games

  • Creating a Lethal Company or Valheim profile no longer fails with "does not say who published it"
  • Newer Steam games, such as Super Battle Golf, show their art in Game select and the game menu
  • The Sims 4 played in German, French, Spanish or Dutch finds its Mods, saves and Options.ini, which the game keeps in a folder named in that language

Launching and loaders

  • A catalog update holding a game this version cannot read no longer sends Mortar back to its built-in catalog; it leaves out only that game
  • When Mortar cannot start, it says why in a message instead of closing without a word, with a button that opens the folder holding its log; on Linux without zenity or kdialog the message arrives as a desktop notification
  • Starting Mortar while it is already open brings its window back even when the page inside had stopped responding
  • A Mortar that has frozen no longer swallows the next start: that start offers to end it and open a fresh one
  • Windows: the installer installs the WebView2 Runtime when it is missing or was removed, says so if that fails, and Mortar asks before starting without it

Downloads and updates

  • What's new no longer shows an error when GitHub cannot serve a release's notes; it waits for the next update instead

Mods and browsing

  • Browse and imports leave out Mortar's own bridges, which Mortar installs itself, so a profile can no longer load a second copy

Saves

  • Lethal Company's Saves lists each slot once: the backup and temporary files the game writes beside a slot belong to it, and each save says whether it is a save slot, an extra slot added by a mod, or the weekly challenge
  • Saves leaves out the Season and Fits columns for games whose saves record neither, such as Lethal Company

Interface and settings

  • Menus are wide enough for their longest item, so Check mods and Mortar for updates is no longer cut off
  • A menu item still cut off at the menu's widest, such as a long profile name, shows its full text on hover
  • Game select's letter rail spreads down the whole window, with letters that grow with it
  • Game select lists the games found on this computer right after the ones you played recently, ahead of the rest of the catalog, and the game menu in the title bar lists only those, with All games for the rest
  • Saves no longer scrolls sideways in the list view
  • An error message names what went wrong instead of "Something went wrong"

0.3.1 2026-10-15

New

Games

  • 46 more games modded through BepInEx and Thunderstore, among them R.E.P.O., Risk of Rain 2, PEAK, Content Warning, Inscryption, Cult of the Lamb, Sun Haven and Enter the Gungeon; 14 of them also browse Nexus Mods
  • The Sims 4: each profile has its own Mods, saves and game options, Tray files go to the game's library, and mods come from CurseForge, Nexus Mods, GitHub, Patreon posts and itch.io pages
  • Games installed through the EA App are found and started
  • The Sims 4: Import from the game's Mods folder reads the mods already in Documents › Electronic Arts › The Sims 4 › Mods, at first set-up and from the Import menu, switched-off files included, and can move them out of that folder

Mods and browsing

  • Paste a Patreon post or an itch.io page in Add mod: it opens in your browser, and the file you save from it is offered and recorded under that page
  • Review the mods in the game's own Mods folder against a profile and bring them in
  • Typing in the mod list jumps to a mod the way Game select does: punctuation is ignored and digits count
  • Find on Nexus: mods imported from another manager or a folder with no page get their Nexus page and file back, from the Source grouping of the Mods list; Set Nexus page… in a mod's menu names the page by hand
  • CurseForge's Install button can open Mortar: turn on Handle CurseForge links in Settings › Downloads; links for games Mortar does not manage go back to the CurseForge app

Profiles and sharing

  • Merge one profile into another, as one step you can undo
  • Scheduled save backups, the run log, the console, conflicts and requirements can be set per profile
  • A profile can keep its own copy of the game's options file
  • Share › Mod list saves the list to a text file, and Multiplayer mod list loads a host's list from one

Launching and loaders

  • Play asks which graphics API to use for games that offer more than one, and asks again after a start that fails under another
  • The game's caches are cleared on the first start after a profile's mods change

Problems and diagnostics

  • Problems lists game settings your mods need switched on, and a Redundant finding can be dismissed and restored

Interface and settings

  • Game select is one alphabetical list with your recently played games on top, a letter rail to jump with, and typing a name finds it
  • The Windows installer offers to open Nexus and Thunderstore links with Mortar, and Mortar offers to take them back when another app claims them
  • Settings › About shows the build, and Open log folder finds the log
  • Join our Discord from the app menu, the Welcome screen and the site

Fixed

Launching and loaders

  • Windows: SMAPI starts when Steam's launch options do not name it, a hidden SMAPI no longer hides the game window, Stop ends the whole game, and no console windows flash when Settings opens
  • A game set up from a folder you chose, or found through another launcher, starts directly instead of being handed to Steam, and on Linux a Windows-only game outside Steam or Bottles says why it cannot start

Mods and browsing

  • A Thunderstore update is found by the package's id, so a namesake cannot hide it, and other mod managers are left out of search and installs
  • The stored Thunderstore listing takes about a quarter of the disk space, loads twice as fast, and leaves memory after ten idle minutes
  • A space typed inside a mod's name no longer switches the focused mod off
  • A config file no mod owns opens alone instead of beside a second list
  • An itch.io key is accepted
  • A mod whose page is not known shows Unknown source instead of Nexus Mods
  • Installing an archive over a mod from a site keeps its page, picture and update checks instead of turning it into a plain Archive

Profiles and sharing

  • Windows: LAN sharing never listens on a network set to Public, and its firewall rules cover every network type so Windows does not prompt
  • Importing from Vortex reads mods it deployed as links
  • Multiplayer mod list: Check reads the text Share › Mod list makes, in all three formats
  • Share › Mod list names a mod once when several parts of one download share its name and version
  • Edit profile no longer scrolls sideways, and a long game list no longer widens the page

Downloads and updates

  • A second Install waits for the running download instead of failing
  • Changing mods no longer puts off the update check
  • A crafted archive or image can no longer make Mortar run out of memory
  • Review updates lists an update from another site that Mortar cannot download itself, instead of counting it and showing nothing
  • A CurseForge Install link for a mod whose author only allows downloads from its page is refused by name with what to do, instead of failing in the queue

Interface and settings

  • Closing the window quits when Mortar is not kept in the tray, and the tray's Quit works with the window closed
  • Tooltips, the reasons a control is off and an update's requirement changes are reachable by keyboard, and the sidebar is one tab stop walked with the arrow keys

0.3.0 2026-10-07

New

  • Lethal Company and Valheim: Mortar finds them, installs BepInEx, and installs mods with all their dependencies. Valheim runs natively on Linux with no Proton needed
  • Thunderstore is a mod source for Lethal Company and Valheim, and CurseForge is a mod source for Stardew Valley
  • Browse searches every source at once, shows one card per mod, and lets you pick the source by its logo; an empty search lists each source's top mods
  • A details panel for every mod: description, versions, dependencies and changelog, with filters by category and sort
  • Load order and Performance tabs for Lethal Company and Valheim: the order plugins load, how long each takes at startup, and frame times and each plugin's cost while you play
  • While the game runs, each mod shows whether it actually loaded, and Mortar records the game version you played
  • Skip the intro is a per-game setting
  • Problems catches much more before you press Play: missing or incompatible plugins, dependency loops, two mods shipping the same plugin, deprecated packages with their replacement, and mods that change the same game code
  • Crash help names the likely cause of a crash, can find the mod behind it by testing halves of your list, and shares the log with one click
  • Import profiles from r2modman, Gale, Vortex and Mod Organizer 2, and share as an r2modman code or a Thunderstore modpack
  • Back up a whole profile to one file, including its saves and mods no site can download again, and restore it as a new profile
  • Pair two computers with a code to send profiles over your local network, or keep them in step through a sync folder
  • One Updates list across all sources, with Update all, a restore point and Undo all
  • A config editor for mods' settings files and their in-game settings menus
  • Steam Deck: play with the gamepad, larger touch targets, and start games in Game Mode
  • Mortar finds games installed in Bottles and launches them through it
  • The browser extension is on the Chrome Web Store for Chrome, Edge and other Chromium browsers
  • Settings has Accounts and Source health pages, a per-game source order, and a search that understands common words

Fixed

  • The mod list, details panel, profile checks and startup are much faster
  • Downloads are checked against the site's hash, and a damaged one is dropped so Retry fetches it again
  • Saves are backed up before every update
  • Only real crashes are reported as crashes, and Stop asks the game to close before ending it
  • SMAPI no longer refuses to start after an earlier crash
  • Errors explain what went wrong instead of saying "Something went wrong"
  • Add to Steam updates its shortcut instead of adding a second one
  • A damaged mod archive fails that one install instead of closing Mortar
  • An update never replaces an unrelated mod that came from the same page
  • Undo covers config edits and keeps a mod's settings when you roll it back
  • Menus and tooltips are solid, lists no longer flash on first draw, and keyboard shortcuts no longer take over Enter, Space and the arrow keys
