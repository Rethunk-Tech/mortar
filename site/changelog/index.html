0.3.16 2026-10-29

Read the 0.3.16 post · Downloads and full changelog for 0.3.16

New

  • Import from Mod Organizer 2 can use a folder you choose, like Vortex's, and reads the base, mod and profile folders MO2 is set to
  • Mortar unpacks lz4 archives, and an archive packed with a compression dictionary too large to unpack safely says so

Changed (4)
  • The config editor says why it refused a value (out of range, not a number, a colour BepInEx cannot read) and when a setting is missing from the file
  • FOMOD installers list steps, groups and options in the order the mod author set
  • Versions are ordered as SMAPI and BepInEx order them, so update checks agree with the game's loader
  • A time more than a minute ahead shows as a date

Fixed (15)
  • BepInEx configs (Lethal Company, Risk of Rain 2) keep each line's own ending and write decimals, large numbers and enum values the plugin can read back
  • MelonLoader configs are never left in a state MelonPreferences.cfg cannot parse
  • Content Patcher packs for Stardew Valley are read as the game reads them: leading or trailing decimal points, empty values and UTF-32 files load, and an unclosed comment or a stray control character is reported as an error on the right line
  • The Proton version shows for a game in a second Steam library
  • Game art and icons also come from Steam libraries added in Settings
  • On Windows: disk usage counts hard-linked files once, a scan with no antivirus provider installed says there is no scanner instead of failing, a shared profile holding a file named like a device (CON, NUL) imports with that one file skipped, and a download still being written into a watched folder waits until it finishes
  • In-game performance measurement picks up loader events reliably
  • GitHub and Nexus rate limits wait only as long as the site asks, the GitHub rate in Settings stays current, and a Nexus collection that stops answering fails instead of hanging
  • A denied Nexus sign-in no longer tells the browser tab it succeeded
  • GitHub downloads accept more archive types, a queued .tar.gz keeps its full name, and a resumed download that restarts from the beginning is saved whole
  • Shared profiles and backups skip file names Windows cannot use, and keep only one of two files whose names differ only by case
  • Desktop shortcuts, the nxm handler and autostart work from a folder whose path has spaces, quotes or a backslash
  • In the Flatpak, saves, other managers' profiles and GOG, Lutris and Bottles games are found under a custom XDG home, and a locked keyring is asked again instead of falling back to plain text
  • A Thunderstore listing, or a GitHub or SMAPI answer, refreshes after the computer's clock was set back
  • Keyboard shortcuts can use the plus key, and work while a checkbox, switch or button has focus

  • The Problems badge counts only the problems you need to fix

  • Replace with on a deprecated mod removes the old one once its replacement installs; one Undo brings both back

Fixed (11)

  • Mortar sees Risk of Rain 2 running, so its in-game performance can be measured

  • Two local archives with the same name each have their own favourite star

0.3.14 2026-10-28

Read the 0.3.14 post · Downloads and full changelog for 0.3.14

New

Develop

  • A new Develop tab for making your own mods, with grid and list views and a filter
  • New mod is a step by step wizard: pick the kind of mod, name it, say what it does, choose a license and its dependencies, and Mortar makes the project from the game's template and its own development profile
  • New mod picks your GitHub account from the ones you are signed in to, checks the name is free, and warns when no installed .NET SDK fits the template
  • Suit and sound mods need no SDK: their project adds your files instead of building
  • New mod can start the development profile with the open profile's mods
  • Add an existing project folder or clone one from GitHub; a project you did not make runs nothing until you trust it
  • Each project card shows the mod's icon, version, build state, when it was last built, whether its files changed since, and its git branch and unpushed work
  • Build, or Build on save to rebuild as you edit; build errors read plainly
  • Test starts the game with your mod, one copy for client-only mods and two or more for multiplayer, laid out in a grid on screen, with the copies meeting in one game for Lethal Company
  • Test copies keep their own saves, so a test never writes your real game's saves
  • Start for debugging opens the game with its debugger listening
  • Release drafts what changed since the last version, then tags and publishes it, through GitHub when the project has one
  • Upload to Thunderstore packs and publishes a mod with your team's token, kept in the system keyring, and can upload the latest release again after an interrupted upload
  • Pack warns while a mod still carries the template's icon
  • Dependencies are required or optional, added from Browse or the wizard, and changed later in Edit details
  • Game code searches the game's code, shows any type as C# or IL side by side, finds where a method is used, and copies a hook for it
  • Open in editor opens a project in VS Code, VSCodium or Rider, whichever is installed
  • A card shows your mod's start-up time and frame cost from its last measured run, and Show log opens its own log in the Console
  • Remove from list can also move the project's folder to the trash, warning first about unpushed or uncommitted work
  • Mods you develop group under In development in Mods, and updates are not offered for them
  • The Updated column shows when a mod in development was last built

Mods

  • Disable asks about the mods that need the one you switch off and the libraries only it needed; Undo switches them all back
  • A switched off mod's config is set aside and comes back when you switch it on again; removing a mod sets its config aside too, so Undo or adding it again brings it back
  • A mod's update badge opens Update review on that mod
  • A mod's menu groups its version actions and its organising actions, with Update in all profiles beside Skip
  • Update review and the patch-day sweep warn about mods on the game's known-broken list
  • Extra mods folders install their mods into a profile you pick per folder, and again whenever the folder changes

Browse

  • Mods known to be broken are marked in Browse and import previews, with the reason and a mod to use instead, and adding one asks first
  • A known-broken mod's working replacement installs in its place and counts for mods that need the original
  • Preferred source can turn a source off for a game, so Browse leaves it out
  • Card stats are small icons, and a possible re-upload is a warning mark with its note in the tooltip

Play

  • Play can start SteamVR or the ALVR dashboard before the game, per game or per profile
  • The Sims 4's DirectX 9 build counts as the game running

Config

  • The config editor marks settings the host enforces or recommends through ConfigSync, and shows the host's value while you are in a game
  • Save host's values keeps the host's ConfigSync values as your own once the game closes

Console

  • Right-click a line to copy it or hide messages like it, from one object or from every object
  • Each game's known noisy messages are hidden by default, and you can show any of them again
  • The levels a game's Console opens with are ticked one by one
  • Copy takes the whole line with its method and object, and right-clicking a selection copies every selected message
  • Hidden messages are listed by where they come from, in a section of their own

Settings

  • A game's settings page switches between every profile's values and the open profile's own, showing each override beside the game's value
  • A setting another one makes moot is disabled and says what to change first

Saves

  • A save's missing mods line can be dismissed until the mods it wants change
  • A backup's Keep forever is its own pin button

Tray

  • Recent profiles sit under a Play submenu per game

  • Dialogs, menus and the sidebar are regrouped and tidied, and the sidebar fits a short window without scrolling

  • Nested mods sit beneath the mod that needs them even when it is in another group
  • Several copies of a game each keep their own log, so their errors count
  • On Linux a Steam game started directly, for several copies or a debug start, runs through Proton in Steam's prefix
  • Merging profiles carries Thunderstore packages, and a merge that fails takes back what it added
  • Cleanup never offers to remove a mod you develop, built or published, and no longer counts toward the Problems badge
  • Profiles added, renamed or deleted from the command line, a share or sync show in the window and the tray at once
  • A missing Thunderstore requirement links to its page and can be added in one click
  • Duplicates found after a run open the same chooser as Problems, and each copy names where it came from
  • Moving the data folder keeps profiles you moved to another folder
  • The backup before Play or an update holds the profile's own saves, never another profile's
  • Removing a mod keeps its settings for Undo, and a mod named BepInEx never takes the loader's own settings with it
  • A damaged Nexus cache file no longer stops Mortar from starting
  • FOMOD installers packed in a subfolder or naming files in another letter case install
  • Heroic's GOG games are found, and so are games and Steam libraries behind a symlink
  • Find the cause no longer blames a framework when one of its content packs crashes the game
  • All sources sorted by downloads or by updated no longer skips mods or shows empty pages
  • Play from a Steam shortcut no longer waits forever when the graphics question is due
  • Bug reports and diagnostics files write your home folder as ~
  • Command palette actions work from Settings and the other full pages
  • The Flatpak finds r2modman and Gale profiles in their usual folders
  • Find the cause asks before it starts relaunching a crashed game

  • Edit profile keeps what you typed when a save is refused

  • Backups reuse the newest one while your saves have not changed

  • Imported settings, packs and shared profiles can no longer set programs, folders, launch prefixes or turn protection off, and shared changes carry text and data files only
  • Signed catalogs and lists cannot be rolled back to older ones, even after clearing the cache
  • Nearby sharing checks and limits what other computers send, and your Nexus key stays out of logs

New

Play

  • The launch screen fills in as the launcher, the game and its loader come up, and stays until the mods have loaded
  • A slow launch says so with Keep waiting, gives up only after five minutes, and Cancel stops a launch at any step
  • A launch waiting on Steam can open Steam's window
  • For Stardew Valley the launch screen stays until the game's window opens, not just until SMAPI has found the mods

Mods

  • Change version lists each version with its release date, marks Latest and Installed, and names the version it installs
  • The details panel keeps a mod's version and what changes it in one section, and leads out through one column of links

Games

  • Add a game starts from the game's program, takes its name and how it is modded from the game's files, and says what each loader suits

Multiplayer and sharing

  • The Multiplayer mod list splits hosting from joining, and Fix all leads once a check finds something
  • An import can install a share as shared: at its versions and without the dependencies it left out
  • The Thunderstore modpack form groups its fields and folds the config list

Saves

  • A save's companion folders travel with it, so Cat Mail Co. backups carry CatLib's mod data

FOMOD

  • A plugin's always-install files, and its install-if-usable files while usable, install even when the plugin is not chosen

  • Dialogs share one look: no dividers, Close as a plain button, and lists that load behind placeholders in their own shape

  • Reduce motion also turns off the press ripple

  • Every Browse page holds 20 mods after adult and hidden mods are dropped, the page count stays put between pages, and pages past the tenth fill
  • A Browse source that leaves mods out for excluded categories counts them as hidden; CurseForge sorted by thumbs-up neither repeats nor skips a mod
  • Signed out of Nexus, Browse and Settings › Accounts no longer raise an error toast
  • A site limiting Mortar's requests says so instead of "Something went wrong"
  • A launch cancelled while it prepares takes its files back out of the game; a cancelled launch ends as cancelled even when the game exits first
  • A game a system Wine runs is found by its path, and Steam, its wrappers or a system program are never taken for the game
  • A game whose log is late counts as started instead of as Steam failing to start it
  • GE-Proton10 ranks above GE-Proton9 when Mortar picks the best Proton
  • Load order follows SMAPI's own order, each mod's dependencies loading just before it
  • FOMOD files go where the installer says: a missing destination installs at the source's path and an empty one in the mod's folder
  • A MelonLoader setting spread over several lines, quoted category names and control characters read and save correctly instead of breaking the file
  • A config number a mod cannot read (1E5, Inf, 300 for a byte) is refused or rewritten so the game keeps it
  • A config search hit names its section, and a .cfg named after its package shows under that package
  • An INI section followed by a comment is found, so a setting is no longer added under a second copy of it
  • Cat Mail Co.'s saves are found
  • A Nexus file uploaded again under the same version counts as the newer one, and one mod id in two games no longer shows the other game's page
  • A Thunderstore dependency with no version or an extra dash is refused instead of misread
  • An ignored Thunderstore, CurseForge or Mod DB link is taken again when clicked again
  • Importing an r2modman or Gale profile keeps config files in BepInEx/config subfolders
  • A failed import removes the profile it made
  • A profile of a game Nexus does not host can be shared by link

  • With beta updates on, a refused prerelease lookup no longer hides a newer stable release
  • Keys saved while the Flatpak secret portal was missing are kept once it answers again
  • Recovery after a crash mid-restore no longer writes your file over the profile's copy, and a leftover link no longer blocks every purge
  • Many screens no longer show another profile's or game's answer when you switch quickly
  • A double click on Retry, Fix and similar actions sends once, and a failure's message offers Retry
  • Screen readers hear headings for each game, profile, save, launcher and first-run step

0.3.12 2026-10-22

New

Languages

  • Mortar is open for translation on Hosted Weblate; Spanish (with Argentina and Panama variants) and Brazilian Portuguese are under way
  • Settings › General › Language lists a language once part of it is translated, with how much is done; following the system language switches only to a language that is mostly translated
  • The tray menu, desktop notifications, file dialogs and startup messages follow the language too
  • Help translate Mortar, beside the Language setting and in the guide, opens the project on Weblate

Linux

  • Graphics in Settings › Appearance: Smoother scrolling for computers where scrolling is slow or the fans spin up in Mortar, as on some graphics cards, and Compatible for a window that stays blank

Problems

  • Every section is on one page, each with its count; Slow startup, Redundant, Cleanup, Replaced and Dismissed are links under the list
  • Each problem has one button for its suggested fix, with the other fixes and Dismiss in its menu, and Why? beside it

Faster

  • Mortar starts with far less work drawing the Mods page
  • Switching a mod on or off rechecks problems sooner, Load order shows dependency names without waiting, and Settings › Storage sizes the data folder in about half the time
  • Searching every mod's settings on the Config page answers in a fraction of the time, most of all for BepInEx games
  • Selecting a mod, opening Settings, the Console and the title bar menus do far less redrawing, and a large profile's problem check after a switch takes a fraction of the time
  • The first problem check after Mortar starts takes about a quarter less time, game settings open without waiting on GitHub each time, the loader's state shows at once on start, and the Config tab's search filters once you pause typing

Wording

  • One word for each thing throughout: Enable and Disable everywhere, and "cannot" rather than "can't"
  • Error messages that said the same thing in different words now use one headline
  • Settings descriptions that only repeated their setting's name are gone

Play

  • Launch options… in the menu beside Play opens the profile's own launch arguments, command prefix and environment variables

Mods list

  • The list's columns follow each mod's own source and loader: Latest, Released, Updated, Rating and Downloads come from Nexus or Thunderstore, whichever the mod is from, and the id column shows a BepInEx plugin's GUID or a SMAPI mod's UniqueID under that name
  • A mod from GitHub shows its latest release, when its installed release came out and its downloads, once Mortar has checked it for updates
  • BepInEx games add Kind (plugin, patcher, library or files only) and Plugin version
  • The column menu is grouped: the mod, its versions, its health, its place in the profile, then its source

Browse

  • GitHub search finds mods under every topic their authors use: Lethal Company searches five topics instead of one (338 repositories instead of 122), Stardew Valley and Vintage Story three each
  • Searching for an author or organisation, such as LethalCompanyModding, lists their GitHub mods too

Fixed (26)
  • Skip the intro for Stardew Valley skips it: the Mortar SMAPI Bridge 0.2.9 that reads the setting now comes with every profile
  • A problem the Console shows for a run, such as a newer copy of a mod you are building loading in place of the installed one, has Dismiss; it stays dismissed in later runs until you choose Restore
  • The Console keeps your place while you read back through the log; new lines scroll it only when it is at the bottom, and dragging its scroll bar keeps up
  • A Nexus download of a BepInEx or MelonLoader mod that is only its DLL installs again; it was refused as an optional file of another mod
  • Add to group no longer shows "Something went wrong in this view" when the profile already has a group
  • Opening a mod's details in Browse keeps that mod on screen instead of jumping to another page
  • Browse's list view shows each mod's picture again; it had shrunk to a sliver under the star, which covered the name's first letter
  • Importing an r2modman profile brings a mod you added to it by hand as a local mod, instead of calling it removed from Nexus with a page link that does not exist
  • The What's new and sync dialogs close with Close
  • Adding a mod's zip that does not say who made it installs it, by Unknown as r2modman names it, instead of refusing it
  • A mod zipped inside its own folder, such as a suit pack with no DLL, installs as its package instead of asking for a mod folder
  • A mod added from a file shows its own icon.png when no site gives it a picture
  • A mod picture with a transparent background shows the card behind it on the Mods tab, as it does in Browse, instead of a coloured square
  • Animated mod pictures (GIF, animated PNG and WebP) play instead of stopping on their first frame
  • Creating a profile while Mortar is adding SMAPI's own mods to every profile no longer fails
  • A controller used in another game no longer controls Mortar in the background: pressing Start to pause that game used to start the open profile's game
  • The extra mods folder lists BepInEx and other Thunderstore games' mods, and a C# project's build folder as one mod, instead of asking each for a SMAPI UniqueID
  • A mod added from an extra mods folder is installed again whenever its folder changes, so a mod you are building stays current in the open profile
  • Importing a Vortex or Mod Organizer 2 profile for a game other than Stardew Valley names each mod from its own package or plugin instead of showing it blank
  • A BepInEx or MelonLoader game no longer offers Import from the game's Mods folder, shows new folders from it on the Mods tab or watches it, which only a Stardew Valley install has
  • The Cleanup list in Settings › Storage and the archive preview name BepInEx, MelonLoader and other Thunderstore mods, and group copies of one package, instead of showing them blank; the Downloads watcher names a Thunderstore zip by its package
  • An archive Mortar cannot install for a BepInEx, MelonLoader or other non-Stardew game is refused with words that say what Mortar expected, instead of "No SMAPI mod was found" or a question about a SMAPI manifest
  • A GitHub release installed for a BepInEx, MelonLoader or other non-Stardew game shows "Could not verify its source" in the queue, since there is no repository check for those games
  • A second Nexus file for a BepInEx, MelonLoader or other non-Stardew mod already in the profile installs as its own mod instead of asking to add it to the first
  • On Windows, a game that crashes stays "Running" until its process has fully closed, so its files are cleaned up and it no longer shows up as a second run of another profile
  • Stop game on Windows no longer fails with "Access is denied" for a game that is already closing, and a game Windows will not let Mortar end says so instead of offering Open storage settings

Profiles and settings

  • Home puts Saves beside Notes, with the changes since the last run below at full width
  • The browser extension reports updates from every site Mortar installs from

Changed (12)

  • Starting Mortar does less work: Content Patcher checks survive a moved data folder, overlay images are not decoded again, the weekly profile check waits until Mortar is idle, and the backdrop is resized once
  • Thunderstore answers from the stored listing at once and refreshes it in the background, and Problems and Browse no longer decode the whole listing
  • The tracked Nexus mods card shows at once from the last list and refreshes behind it
  • The Launch menu on Home is called Tools, so it no longer reads as starting the game

  • Thunderstore is a mod source for Lethal Company and Valheim, and CurseForge is a mod source for Stardew Valley
  • Browse searches every source at once, shows one card per mod, and lets you pick the source by its logo; an empty search lists each source's top mods
  • A details panel for every mod: description, versions, dependencies and changelog, with filters by category and sort
  • Load order and Performance tabs for Lethal Company and Valheim: the order plugins load, how long each takes at startup, and frame times and each plugin's cost while you play
  • While the game runs, each mod shows whether it actually loaded, and Mortar records the game version you played
  • Skip the intro is a per-game setting
  • Problems catches much more before you press Play: missing or incompatible plugins, dependency loops, two mods shipping the same plugin, deprecated packages with their replacement, and mods that change the same game code
  • Crash help names the likely cause of a crash, can find the mod behind it by testing halves of your list, and shares the log with one click
  • Import profiles from r2modman, Gale, Vortex and Mod Organizer 2, and share as an r2modman code or a Thunderstore modpack
  • Back up a whole profile to one file, including its saves and mods no site can download again, and restore it as a new profile
  • Pair two computers with a code to send profiles over your local network, or keep them in step through a sync folder
  • One Updates list across all sources, with Update all, a restore point and Undo all
  • A config editor for mods' settings files and their in-game settings menus
  • Steam Deck: play with the gamepad, larger touch targets, and start games in Game Mode
  • Mortar finds games installed in Bottles and launches them through it
  • The browser extension is on the Chrome Web Store for Chrome, Edge and other Chromium browsers
  • Settings has Accounts and Source health pages, a per-game source order, and a search that understands common words

Fixed (11)
  • The mod list, details panel, profile checks and startup are much faster
  • Downloads are checked against the site's hash, and a damaged one is dropped so Retry fetches it again
  • Saves are backed up before every update
  • Only real crashes are reported as crashes, and Stop asks the game to close before ending it
  • SMAPI no longer refuses to start after an earlier crash
  • Errors explain what went wrong instead of saying "Something went wrong"
  • Add to Steam updates its shortcut instead of adding a second one
  • A damaged mod archive fails that one install instead of closing Mortar
  • An update never replaces an unrelated mod that came from the same page
  • Undo covers config edits and keeps a mod's settings when you roll it back
  • Menus and tooltips are solid, lists no longer flash on first draw, and keyboard shortcuts no longer take over Enter, Space and the arrow keys
