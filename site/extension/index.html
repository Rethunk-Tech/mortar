Browser extension

Mod sites, aware of your profile.

See what your profile already has while you browse Nexus Mods, Thunderstore, CurseForge, the Vintage Story Mod DB, Paradox Mods or Modrinth, and send their install buttons to Mortar. Firefox, Chrome, Edge and other Chromium browsers.

Get it for Firefox

Free and open source. Needs Mortar on the same computer.

What it does

Three jobs, on the pages you already use.

Mod Manager Download, into Mortar

Click Nexus's own Mod Manager Download button and the file goes to the right Mortar profile. The extension never starts a download by itself.

Marks what you have

Mod pages, file lists and search results show which mods and files the open profile already has, so you don't download twice.

Updates and warnings

The toolbar popup lists updates for the mods in your profile and flags broken or obsolete mods on their pages.

Install

  1. Firefox: open the downloaded .xpi in Firefox, or drop it on about:addons, and confirm.
  2. Chrome and Edge: choose Add to Chrome on the Chrome Web Store page. Edge installs it from the same page.
  3. In Mortar, open Settings › Downloads. It shows the extension as connected once you visit Nexus Mods.

Privacy

It talks only to Mortar.

That means the Mortar app on your own computer, reached through the browser's native messaging. The extension has no server, no analytics and no telemetry.

Privacy policy

Mortar's browser extension reads Nexus Mods, Thunderstore, CurseForge, Vintage Story Mod DB, Paradox Mods and Modrinth pages in your browser to mark mods and to pass their install links to the Mortar desktop app installed on your own computer, using the browser's native messaging. The only data exchanged is Nexus mod ids, file ids and nxm:// links, Thunderstore package names, CurseForge project ids, mod names and curseforge:// links, Mod DB mod ids and install links, and Paradox Mods and Modrinth project ids, going to Mortar, and installed-mod and update information coming back. It runs only on https://www.nexusmods.com, Thunderstore community and package pages (https://thunderstore.io/c/*), https://www.curseforge.com, https://mods.vintagestory.at, https://mods.paradoxplaza.com and https://modrinth.com. The extension makes no network requests of its own, has no server, analytics or telemetry, and sends nothing to the developers or any third party. Your display choice and filter settings are stored in your browser's extension storage and never leave it. Uninstalling the extension removes them.

Permissions it asks for

nativeMessaging to reach Mortar on your computer; access to www.nexusmods.com, to read and mark its pages, to Thunderstore pages, to mark a package and add its Install in Mortar button, to www.curseforge.com and mods.vintagestory.at, to mark mods and hand their Install buttons to Mortar, and to mods.paradoxplaza.com and modrinth.com, to mark mods and add Install in Mortar; scripting to add its marks to tabs of those sites that were already open when it was installed; storage for your display settings; alarms to refresh the update check.

Source code

Every line is public at github.com/Rethunk-Tech/mortar-browser-extension, with no build step: the files in the release are the files in the repository.
