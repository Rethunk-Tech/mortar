FAQ

Questions

Short answers about Mortar. The user guide covers everything in detail, and the Discord help forum answers the rest.

Is Mortar free?

Yes. It's AGPL-3.0, and the app has no account, ads or tracking.

Which games does it support?

333 games. Mortar finds them on Steam (the Flatpak Steam too), GOG, Epic, the EA app, the Xbox app, Heroic, Lutris and Bottles, or in a folder you choose.

Coming from another mod manager?

Mortar imports profiles from r2modman, Gale, Vortex, Mod Organizer 2 and Stardrop.

Do I need Nexus Mods Premium?

No. With a free Nexus account you click Mod Manager Download on the mod's page. Premium can also download from inside Mortar.

Does Mortar host mod files?

No. Each mod downloads from its own page on Nexus Mods, CurseForge, GitHub, Thunderstore, Vintage Story Mod DB, Paradox Mods, itch.io, or Patreon. The one exception is a LAN send between your own computers.

Does Mortar work on the Steam Deck?

Yes. Install the AppImage in Desktop Mode, then close Steam and use a profile's Add this profile to Steam to play it from Game Mode. The Flatpak cannot add itself to Steam.

Windows says it protected my PC. Is that normal?

Yes. The builds are not code-signed, so SmartScreen warns once. Choose More info, then Run anyway.

How do I know a download is genuine?

GitHub Actions builds every release from the public source. The package repositories, the Flatpak and the checksums are signed, and Mortar checks a signature before it installs an update. More in code signing.

What happened to Concrete?

Concrete is archived, and Mortar is its successor.

Where do I report a bug?

Use Report a bug in the Mortar menu, which attaches diagnostics, or open a GitHub issue.
