Start modding Pulsar: Lost Colony

  1. Download Mortar for Linux or Windows and open it.
  2. Pick Pulsar: Lost Colony. Mortar installs BepInEx 5 and makes your first profile.
  3. Open Browse, add the mods you want, and press Play. Each profile keeps its own mods and settings.

Share a profile

A shared Pulsar: Lost Colony profile is a link to mortar.rethunk.tech/pulsar-lost-colony/p. Whoever opens it sees the mod list and imports it in one click. The profile lives inside the link, so nothing is uploaded.
