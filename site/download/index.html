Mortar

Download

Mortar finds a game, installs its mod loader, keeps each set of mods in its own profile, and launches the game with the chosen profile.

The first release is for Stardew Valley on Linux and Windows. Mortar never re-hosts mod files; downloads come from each mod's own source.

Linux

Download the AppImage, mark it executable, and run it. The first run registers a desktop entry, icon, and handlers for mortar:// links and .mortar files.

Download AppImage 
chmod +x mortar-linux-x86_64.AppImage
./mortar-linux-x86_64.AppImage

Prefer a package? Get the Flatpak, or the .deb, .rpm and Arch packages from the latest release (x86_64 and ARM64). To get updates through apt, dnf or pacman, add the Mortar package repository.

Windows

Download the installer. It installs for your user under %LOCALAPPDATA%\Programs\Mortar and does not need administrator rights.

Download installer (x64)

On Windows on ARM, use the ARM64 installer.

Builds are unsigned. Microsoft Defender SmartScreen may show “Windows protected your PC”. Click “More info”, then “Run anyway”.

There is no paid code-signing certificate yet. The source is public at github.com/Rethunk-Tech/mortar.
