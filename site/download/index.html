Download

Get Mortar. It's free.

It's open source too. Mortar runs on Windows and Linux, x64 and ARM64, and on the Steam Deck.

For your system.

Windows 10 and 11. Mortar installs for your user, so it needs no administrator rights. It needs Microsoft's WebView2 Runtime, which the installer adds when missing.

Installer, x64Most PCs Installer, ARM64Snapdragon and other ARM PCs Portable, x64Runs from any folder Portable, ARM64Runs from any folder
  1. Run the installer. It puts Mortar in %LOCALAPPDATA%\Programs\Mortar and adds Start Menu and Desktop shortcuts.
  2. The builds are not code-signed, so SmartScreen says “Windows protected your PC” the first time. Choose More info, then Run anyway.
  3. Mortar updates itself from then on.

Scoop

From Mortar's own bucket, with every download pinned by its SHA-256. Scoop then handles updates. 

scoop bucket add mortar https://github.com/Rethunk-Tech/scoop-bucket
scoop install mortar/mortar

Any distribution with Flatpak, x86_64 or aarch64. The link adds Mortar's signed repository to GNOME Software, KDE Discover or your app store, which then keeps Mortar up to date.

Install with FlatpakOpens in your software center

The sandbox only sees the usual game folders. For a game installed elsewhere, run flatpak override --user --filesystem=<folder> tech.rethunk.Mortar.

The AppImage and the portable program run on Ubuntu 24.04, Debian 13, Fedora 39 or a newer Linux (glibc 2.38) and update themselves in place. A single package installs without updates.

To run the x86_64 AppImage:

chmod +x mortar-linux-x86_64.AppImage
./mortar-linux-x86_64.AppImage

The first run adds Mortar to your applications menu and takes nxm:// links and .mortar files.

Ubuntu 24.04, Debian 13 or newer, on amd64 and arm64. Mortar then updates with the rest of your system. 

sudo apt update && sudo apt install curl
sudo curl -fsSLo /usr/share/keyrings/mortar-archive-keyring.gpg https://mortar.rethunk.tech/packages/mortar-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/mortar.list https://mortar.rethunk.tech/packages/mortar.list
sudo apt update && sudo apt install mortar

Fedora 39 or newer, on x86_64 and aarch64. dnf asks once to import the key; check its fingerprint against the one under Verify your download. 

sudo curl -fsSLo /etc/yum.repos.d/mortar.repo https://mortar.rethunk.tech/packages/mortar.repo
sudo dnf install mortar

x86_64 and aarch64. These commands trust the Mortar key, add the repository to /etc/pacman.conf and install. 

curl -fsSL https://mortar.rethunk.tech/packages/mortar-archive-keyring.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key D8B1C4C205C5FB3633CB8B9900B75959B637DCB5
curl -fsSL https://mortar.rethunk.tech/packages/pacman.conf | sudo tee -a /etc/pacman.conf
sudo pacman -Syu mortar

Any distribution with Flatpak, x86_64 or aarch64. This adds Mortar's signed Flatpak repository, so flatpak update keeps it current. 

flatpak install --user https://mortar.rethunk.tech/packages/flatpak/tech.rethunk.Mortar.flatpakref

From Mortar's own tap, pinned by SHA-256. It installs the AppImage, which needs FUSE 2 (libfuse2). Homebrew then handles updates. 

brew install rethunk-tech/tap/mortar

The Steam Deck runs the x86_64 AppImage. Mortar sets up in Desktop Mode, then each profile can be played from Game Mode.

AppImage, x86_64For the Steam Deck
  1. Switch to Desktop Mode and download the AppImage.
  2. Mark it executable: right-click it, Properties, Permissions, then Is executable. Run it.
  3. Set up your game, close Steam, then open a profile's menu and choose Add this profile to Steam. The profile appears in Game Mode, and playing it there starts the game with that profile's mods.

The Flatpak cannot add itself to Steam, so use the AppImage on the Deck. Mortar updates itself in place.

Optional. It marks Nexus Mods, Thunderstore, CurseForge, Vintage Story Mod DB, Paradox Mods and Modrinth pages with what your profile already has, and sends their install buttons to Mortar. What it does, and privacy.

Verify your download

Every release carries SHA256SUMS, signed with the Mortar packages key, and a GitHub build provenance attestation for each file. With the downloaded file in the current folder:

In PowerShell. gpg comes with Gpg4win, gh is the GitHub CLI.

$f = 'mortar-amd64-installer.exe'
$base = 'https://github.com/Rethunk-Tech/mortar/releases/download/v0.3.16'
Invoke-WebRequest "$base/SHA256SUMS" -OutFile SHA256SUMS
Invoke-WebRequest "$base/SHA256SUMS.asc" -OutFile SHA256SUMS.asc
Invoke-WebRequest https://mortar.rethunk.tech/packages/mortar-archive-keyring.asc -OutFile mortar.asc
gpg --import mortar.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
$want = (Select-String -Path SHA256SUMS -Pattern "  $([regex]::Escape($f))$").Line.Split(' ')[0]
if ((Get-FileHash $f).Hash -eq $want) OK else MISMATCH
gh attestation verify $f --repo Rethunk-Tech/mortar

In a terminal.

f=mortar-linux-x86_64.AppImage
curl -fsSLO https://github.com/Rethunk-Tech/mortar/releases/download/v0.3.16/SHA256SUMS
curl -fsSLO https://github.com/Rethunk-Tech/mortar/releases/download/v0.3.16/SHA256SUMS.asc
curl -fsSL https://mortar.rethunk.tech/packages/mortar-archive-keyring.asc | gpg --import
gpg --verify SHA256SUMS.asc SHA256SUMS
grep "  $f\$" SHA256SUMS | sha256sum --check
gh attestation verify "$f" --repo Rethunk-Tech/mortar

One key, “Mortar packages <opensource@rethunk.tech>”, signs every release's SHA256SUMS and the apt, dnf, pacman and Flatpak repositories, so every download checks against the same fingerprint: D8B1 C4C2 05C5 FB36 33CB 8B99 00B7 5959 B637 DCB5. Code signing policy

Checksums, release notes and every build: latest release on GitHub.
