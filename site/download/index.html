Download Mortar

Free and open source. The latest release for Windows and Linux, on x64 and ARM64, and the Steam Deck.

Windows 10 and 11. Mortar installs for your user, so it needs no administrator rights.

Installer, x64Most PCs Installer, ARM64Snapdragon and other ARM PCs Portable, x64Runs from any folder Portable, ARM64Runs from any folder
  1. Run the installer. It puts Mortar in %LOCALAPPDATA%\Programs\Mortar and adds Start Menu and Desktop shortcuts.
  2. The builds are not code-signed, so SmartScreen says “Windows protected your PC” the first time. Choose More info, then Run anyway.
  3. Mortar updates itself from then on.

To check the download before running it, see the code signing policy.

Scoop

From Mortar's own bucket, with every download pinned by its SHA-256. Scoop then handles updates. 

scoop bucket add mortar https://github.com/Rethunk-Tech/scoop-bucket
scoop install mortar/mortar

Install from the package repository and Mortar updates with the rest of your system. Pick your distribution:

Ubuntu 24.04, Debian 13 or newer, on amd64 and arm64. 

sudo curl -fsSLo /usr/share/keyrings/mortar-archive-keyring.gpg https://mortar.rethunk.tech/packages/mortar-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/mortar.list https://mortar.rethunk.tech/packages/mortar.list
sudo apt update && sudo apt install mortar

Or install a single .deb without updates: sudo apt install ./mortar_*_amd64.deb

Fedora 39 or newer, on x86_64 and aarch64. dnf asks once to import the key; check its fingerprint against the one below. 

sudo curl -fsSLo /etc/yum.repos.d/mortar.repo https://mortar.rethunk.tech/packages/mortar.repo
sudo dnf install mortar

Or install a single .rpm without updates: sudo dnf install ./mortar-*.rpm

x86_64 and aarch64. These commands trust the Mortar key, add the repository to /etc/pacman.conf and install. 

curl -fsSL https://mortar.rethunk.tech/packages/mortar-archive-keyring.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key D8B1C4C205C5FB3633CB8B9900B75959B637DCB5
curl -fsSL https://mortar.rethunk.tech/packages/pacman.conf | sudo tee -a /etc/pacman.conf
sudo pacman -Sy mortar

Or install a single package without updates: sudo pacman -U mortar-*.pkg.tar.zst

Any distribution with Flatpak, x86_64 or aarch64. It brings its own libraries, so it also runs on older systems. This adds Mortar's signed Flatpak repository, so flatpak update keeps it current; the GNOME runtime comes from Flathub. 

flatpak install --user https://mortar.rethunk.tech/packages/flatpak/tech.rethunk.Mortar.flatpakref

The sandbox only sees the usual game folders. For a game installed elsewhere, run flatpak override --user --filesystem=<folder> tech.rethunk.Mortar. A single bundle file is also on each release, without updates.

The Steam Deck runs the x86_64 AppImage. Mortar sets up in Desktop Mode, then each profile can be played from Game Mode.

AppImage, x86_64For the Steam Deck
  1. Switch to Desktop Mode and download the AppImage.
  2. Mark it executable: right-click it, Properties, Permissions, then Is executable. Run it.
  3. Set up your game, then open a profile's menu and choose Add to Steam. The profile appears in Game Mode, and playing it there starts the game with that profile's mods.

The Flatpak cannot add itself to Steam, so use the AppImage on the Deck. Mortar updates itself in place.

Optional. It marks Nexus Mods pages with what your profile already has and hands Mod Manager Download clicks to Mortar. Mortar's Settings › Downloads links it too. What it does, and privacy.

Verify your download

Every release carries SHA256SUMS, signed with the Mortar packages key, and a GitHub build provenance attestation for each file. With the downloaded file in the current folder: 

curl -fsSLO https://github.com/Rethunk-Tech/mortar/releases/latest/download/SHA256SUMS
curl -fsSLO https://github.com/Rethunk-Tech/mortar/releases/latest/download/SHA256SUMS.asc
curl -fsSL https://mortar.rethunk.tech/packages/mortar-archive-keyring.asc | gpg --import
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
gh attestation verify <file> --repo Rethunk-Tech/mortar

The key's fingerprint is D8B1 C4C2 05C5 FB36 33CB 8B99 00B7 5959 B637 DCB5. More in the code signing policy.
