# Security policy

This repository is private until its first release; the licence is in [`LICENSE`](LICENSE).

## Reporting a vulnerability

Do not open an issue for a security report. Use GitHub's private vulnerability reporting on this repository, or contact the Rethunk-AI organisation maintainers privately, with a description, the affected paths or version, steps to reproduce, and the impact.

## Supported versions

Only the tip of `main` is supported.
