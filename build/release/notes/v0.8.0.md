## New

- Skyrim Special Edition, Skyrim, Fallout 4, Fallout: New Vegas and Starfield: Mortar writes the plugin list in LOOT's default order, keeps archives and plugins whole, and starts the script extender when it is installed
- Minecraft profiles are Java instances with Fabric, Forge or NeoForge
- Mortar's window is translucent and shows the desktop through it; on GNOME 51 and later it also blurs what is behind it
- A mod's description in Browse has a Translate button that shows it in your language
- Develop can start a Lethal Company scrap item
- The load order lists BepInEx plugins that will not load, with the reason
- Stopping an in-game measurement in Stardew Valley ends it in the game too
- Planet Zoo, Graveyard Keeper and Hogwarts Legacy are found on Epic, Darkest Dungeon on GOG and Epic, and Starbound on Xbox
- 52 more BepInEx 5 games get Mortar's companion mod
- Mortar warns that the GOG copy of Graveyard Keeper cannot load plugins

## Changed

- A profile code that carries DLL files installs them only when you tick the option to
- Pairing computers over the LAN uses a new exchange: update Mortar on both computers to pair or send

## Fixed

- The AppImage opens your browser for Nexus sign-in and links on desktops where it failed silently, such as KDE Plasma with LibreWolf
- A file you edited in the game folder is kept when its mod updates or rolls back, and set aside only when another mod takes it over
- A Nexus download is refused when its file list cannot be checked, instead of installing unchecked
- A download that redirects off https is refused
- Changing a setting in a mod's config.json keeps the rest of the file as you wrote it
- Mortar no longer reopens at a minimised window's off-screen position
- Modrinth's wait time shows when it is busy
