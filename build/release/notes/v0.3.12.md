## New

### Languages

- Mortar is open for translation on Hosted Weblate; Spanish (with Argentina and Panama variants) and Brazilian Portuguese are under way
- Settings › General › Language lists a language once part of it is translated, with how much is done; following the system language switches only to a language that is mostly translated
- The tray menu, desktop notifications, file dialogs and startup messages follow the language too
- Help translate Mortar, beside the Language setting and in the guide, opens the project on Weblate

### Linux

- Graphics in Settings › Appearance: Smoother scrolling for computers where scrolling is slow or the fans spin up in Mortar, as on some graphics cards, and Compatible for a window that stays blank

### Wording

- One word for each thing throughout: Enable and Disable everywhere, and "cannot" rather than "can't"
- Error messages that said the same thing in different words now use one headline
- Settings descriptions that only repeated their setting's name are gone

## Fixed

- Add to group no longer shows "Something went wrong in this view" when the profile already has a group
- Opening a mod's details in Browse keeps that mod on screen instead of jumping to another page
- Importing an r2modman profile brings a mod you added to it by hand as a local mod, instead of calling it removed from Nexus with a page link that does not exist
- The What's new and sync dialogs close with Close
