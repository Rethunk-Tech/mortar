## New

- Cyberpunk 2077: Mortar lays out each download the way Vortex does, from Cyber Engine Tweaks, RED4ext and redscript to REDmods and plain archives, and keeps their files together
- Cyberpunk 2077 loads archive mods in your profile's order, compiles REDmods before the game starts, and always starts the game modded
- A mod's menu can turn an archive mod into a REDmod, and back
- The Tools menu runs a game's own tools with your profile: REDLauncher, REDmod deploy and CyberCAT for Cyberpunk 2077
- A download Mortar has no layout for shows its files and asks whether to install it as packed
- Installing an old core mod, or files that overwrite a game's config, asks first, as Vortex does
- Show › Mod parts hides the extra mods a download carries

## Fixed

- A missing requirement in a game other than Stardew Valley no longer names an unrelated Stardew Valley mod, and a mod added under that name gets its own name back
- The launch screen no longer cuts off a step's longer captions
- A mod added from your own archive in a game like Cyberpunk 2077 or The Sims 4 is named without the archive's .zip ending
