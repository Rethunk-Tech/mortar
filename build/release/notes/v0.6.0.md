## New

- Nexus Mods sign-in happens in your browser: choose Sign in to Nexus Mods in Settings › Accounts and approve Mortar. If a sign-in is already in progress, the button shows Cancel
- Desktop notifications go through the system portal, and clicking one brings Mortar back to what it was about
- The Flatpak builds mods with Flathub's .NET SDK extension, and New mod prints the install command when the extension is missing
- Game code in Develop is offered whenever the game's install is known, with or without a mod project
- The stream overlay for Stardew Valley adds weekday, days left, friend and pet fields
- Develop's diagnostics zip carries each project's last build log, and mortar.log gets a line per build

## Changed

- Personal Nexus API keys are gone, and Mortar deletes a saved one, so sign in again once
- Nexus Mods and GitHub request counts in Settings › Accounts say what time they reset
- The Flatpak keeps sign-ins in a sealed file, using your desktop's Secret portal
- Menus follow one order: the main action first, and an ellipsis only on items that ask for more input
- Develop names the Thunderstore team an upload goes out as, and Release everywhere says Nexus was skipped when you are not signed in

## Fixed

- Games that load from a folder and have no ordering extension no longer show a broken Load order tab
- Mortar finds a Proton prefix in any Steam library, not only the game's own
- The Flatpak finds a .NET install in your home folder's .dotnet, and the dedicated server and the code decompiler run with the Flatpak's own dotnet
- Removing a Develop project that something still holds names the programs holding the folder
- A build queued behind Trash refuses instead of building a project that is gone
- Reset all in a Stardew Valley config is one restore point
- Endorse prompts are counted per game, so Never in one game no longer silences the same mod number in another
- nxm links from an install that is not an AppImage no longer open another AppImage
- A failed share import is undone before its preview comes back
- A FOMOD item is laid out in the store's own cache
