## Fixed

- Shares, packs, collections and saves in games other than Stardew Valley no longer name or add Stardew Valley mods as requirements, and a mod already saved under a Stardew Valley name gets its own name back, even offline
- Mods an earlier release split into one entry per file are joined back together, so their XML, presets and sounds load again
- Updating a mod keeps its note, tags, pin, REDmod conversion and whether it is switched off
- Cyberpunk 2077: two mods with loose scripts of the same name no longer overwrite each other
- Cyberpunk 2077: a modlist.txt you or another manager wrote is set aside and put back, never deleted or overwritten
- Cyberpunk 2077: the game no longer starts with an old archive order when Mortar cannot write the new one; the launch stops and says why
- Cyberpunk 2077: archives ending in .ARCHIVE install, and so does a REDmod with a slash in its name
- The Tools menu and the REDmod check use the game install your profile runs
- Mods their Nexus authors marked obsolete or deprecated are flagged on Problems, even offline
- A download stopped to ask about its layout says so on its row
- The Config page names the mod whose settings it shows, even when the filter hides that mod
- A profile's row on the Profiles page counts missing mods as problems, as the header does
- Browse shows its placeholder at once, and Problems says it is still checking instead of "No problems found" while it loads
- The launch screen marks the game with its first letter when its Steam icon is missing
