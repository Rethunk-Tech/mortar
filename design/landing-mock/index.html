    Features

    Built for big mod lists.

    Hundreds of mods, several playthroughs, friends on the same pack. That is the setup Mortar was built for.

    A profile per playthrough

    Its own mods, settings and launch options. Switching is one click.

    Every mod site in one search

    One card per mod across six sites; dependencies come along.

    Shares as a link

    A whole profile in one link. Friends import it in a click.

    Problems explained

    Missing dependencies, conflicts and crashes in plain words, each with a fix.

    See what slows startup

    Time to title screen and what each mod costs, compared with the last launch.

    Scanned before it installs

    Each mod goes past your antivirus after unpacking and before it reaches the game.

    Steam Deck

    Play from
    Game Mode.

    Add a profile to Steam and start it from Game Mode like any other game. Mortar stays out of sight, asks only when something needs an answer, and closes with the game so Steam counts your playtime.

    • A gamepad moves focus, confirms, goes back and plays
    • Larger targets, laid out for the Deck's 1280×800 screen

    Your PCs

    Your profiles on
    every computer.

    Pair two of your computers with a short code. A profile you send arrives with its mod files, so nothing downloads twice. No account is involved.

    • Nearby computers are found on your network
    • The code works once, for five minutes

    Companions

    Works with your browser and your game.

    Two optional add-ons, both open source, both installed from inside Mortar.

    Browser extension

    Marks Nexus Mods and Thunderstore pages with what your profile already has, and hands downloads to Mortar. Firefox, Chrome and Edge.

    Game bridge

    A small mod in each profile. In Stardew Valley it runs console commands and records startup timings; in Lethal Company and Valheim it reports which plugins loaded.

    Is Mortar free?

    Yes. AGPL-3.0; no account, ads or tracking in the app.

    Coming from another mod manager?

    Mortar imports profiles from r2modman, Gale, Vortex, Mod Organizer 2 and Stardrop.

    Do I need Nexus Mods Premium?

    No. With a free account, use Mod Manager Download on the mod's page. Premium can also download from inside Mortar.

    Does Mortar host mod files?

    No. Each mod downloads from its own page. The one exception is sending a profile between your own computers.

    Does Mortar work on the Steam Deck?

    Yes. Run the AppImage in Desktop Mode, then use a profile's Add to Steam for Game Mode.

    Windows says it protected my PC. Is that normal?

    Yes. The builds are not code-signed, so SmartScreen warns once. Choose More info, then Run anyway.
