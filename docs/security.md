# Security model

What Mortar treats as untrusted input, the code that refuses it, and the test that fails if the guard goes. Reporting a vulnerability and verifying downloads: [SECURITY.md](../SECURITY.md). Paths are relative to `internal/` unless they start with `main.go`.

Mortar runs as the signed-in user and has no elevated component, so every guard below protects the user's own files from a crafted download, pack, link, peer or page.

Each input also has a Go fuzz test, named in its row, in its package's `fuzz_test.go`. `go test` runs only the seeds and the minimised crashers committed under `testdata/fuzz/`; `go test -fuzz=FuzzX -fuzztime=2m ./internal/<package>` explores further.

## Imports and extraction

| Surface | Threat | Guard | Test |
| --- | --- | --- | --- |
| r2modman and modpack imports | A pack writes outside the loader's folder, or over the profile's own records (`profile.json`, saves, launch prefix) | `internal/packsvc/service.go:232` `packFiles` keeps only files below a loader's `ImportRoots` (`internal/loader/bepinex5/driver.go:65`), written under the root's own spelling | `TestImportWritesNothingOutsideTheLoaderFolder`, `TestPackFilesLandUnderBepInEx` (`internal/packsvc/service_test.go`), `FuzzParseR2Zip`, `FuzzGaleRows` (`pack`) |
| Executables in a pack | A pack carries a `.dll`, `.exe` or script that r2modman itself would refuse | `internal/packsvc/service.go:222` `blockedExtensions`, checked after name normalisation | `TestPackFilesJudgeNamesAsWindowsStoresThem` |
| Pack zip and mod names | Traversal, drive letters, a zip bomb, a mod name that climbs out of its folder | `internal/pack/pack.go:89` `readZip` refuses `..`, absolute and `:` paths and caps entries (`maxEntries`), per-file and total size; `refs` validates package names | `TestHostilePacksAreRefused` (`internal/pack/pack_test.go`), `FuzzModpackManifest` |
| Trailing-dot and Windows names | `evil.dll.` stores as `evil.dll` on Windows and slips past an extension check; `CON`, `NUL.txt` open devices | `internal/winname/winname.go:11` `Valid` refuses reserved characters, trailing dot or space and device names; `internal/packsvc/service.go:260` `winPath` trims then judges, so a pack file is judged as Windows stores it; archives, layouts and the installer share `winname` | `TestValidAndClean` (`winname`), `TestUnsafeEntriesRejected` (`archive`), `TestPackFilesJudgeNamesAsWindowsStoresThem`, `FuzzCleanName` (`archive`) |
| Archive extraction (zip, RAR, 7z, tar, gzip, xz, lzma, zstd, bzip2) | Traversal, absolute paths, links, device files, duplicate or case-colliding names, size and entry bombs, wrong checksum, encrypted entries | `internal/archive/archive.go:390` `admit` and `:419` `cleanName` (traversal, `winname`, case collision, entry cap); `:321` `checkKind` and `stream.go:175` `stream` with `tarKind` (symlink, hardlink, device, pipe and sparse tar entries); `:359` `write` (`O_EXCL`, byte cap counted on actual bytes, CRC) | `TestUnsafeEntriesRejected`, `TestNothingWrittenOutsideDest`, `TestLinksAndSpecialFilesRejected`, `TestCaseCollision`, `TestCaps`, `TestCapCountsActualBytesNotDeclared`, `TestChecksumMismatch`, `TestEncryptedRejected`, `TestStreamFormatsRefuseUnsafeEntries`, `TestStreamFormatsHonourTheSizeAndEntryCaps`, `FuzzExtract` (raw bytes of every format), `FuzzExtractStreams` (compressed and tar seeds), `FuzzExtractZipEntries` (fuzzed names and modes) |
| Decompression bombs in tar and single-file streams | A few kilobytes of gzip, xz, lzma, zstd or bzip2 unpack to gigabytes, a header asks the decoder for a huge window, or tar padding and unread entries decompress without being counted | `internal/archive/stream.go:69` `capReader` caps everything a stream decompresses at the total cap plus 1.5 KiB per allowed entry; `:100` `openPayload` limits xz, lzma and zstd windows to 256 MiB (`dictLimit`); entries then go through the same `write` byte cap as zip | `TestStreamBombIsStoppedByTheDecompressionBudget`, `FuzzExtractStreams` |
| Manifest peek on a downloaded archive | A crafted zip in Downloads whose `manifest.json` inflates to gigabytes before the capped extractor ever runs | `internal/dlwatch/peek.go:14` `maxManifestBytes` skips entries declaring more and `LimitReader` caps the actual read | `TestPeekNameSkipsAnOversizedManifest` |
| 7z reader panics and decoder memory | A crafted 7z header panics the third-party reader or asks for gigabytes of decoder memory | `internal/archive/archive.go:87` `RecoverMalformed` and `:95` `OpenSevenZip` turn a panic into `ErrMalformed`; `internal/archive/sevenzip_limits.go:22` pre-parses the header against limits. the `forbidigo` rule in `.golangci.yml:71` bans `sevenzip.NewReader` and `OpenReader` outside `OpenSevenZip` | `TestDecoderMemoryHeadersRejected` (`archive`), `TestCrashingCollectionArchiveIsMalformed` (`internal/sharesvc/collection_test.go`), `FuzzExtract` |
| FOMOD destinations | A FOMOD `<file destination="../other-mod">` writes into another mod or outside the mods folder | `internal/installer/fomod.go:46` and `:56` refuse a source that is not a valid path and a destination that climbs; `internal/installer/installer.go:110` `validate` re-checks every layout file for target, `..`, absolute paths, `winname` and depth | `TestLayoutRefusals` (`installer`), `FuzzFOMODLayout` (every file lands inside the package's own folder) |
| r2modman and Gale profile codes | A pasted code carries a hostile zip, a package name that is not one, or a path out of the profile | `internal/pack/r2modman.go:92` `Code.Parse` caps the text, decodes the zip and reads it through the same `readZip` and package-name checks as a pack file | `FuzzCode` (`pack`) |
| Thunderstore packages | A package's file climbs out of `BepInEx/`; its manifest names a malformed dependency | `loader/bepinex5/bepinex5.go:265` `Route` refuses `..`, absolute and `:` paths and a package name with a separator; `ParseManifest` dependencies go through `deps.Thunderstore` | `FuzzRoute`, `FuzzParseManifest` (`loader/bepinex5`) |
| SMAPI manifests | A crafted `manifest.json` panics the scan, or an update key steers a GitHub request | `internal/manifest/manifest.go:73` `Parse` reads leniently and needs a UniqueID; `GitHubUpdateKey` takes only a plain owner/repo (`ValidGitHubRepo`), which the download queue checks too | `TestGitHubRepoRefusesWhatMovesTheURL`, `FuzzParse` (`manifest`) |
| BepInEx plugin DLLs | A truncated or crafted assembly panics the plugin scan that every install runs | `internal/dotnet/dotnet.go:182` `malformed` turns an out-of-range read in `Plugins` and `Writes` into an error | `FuzzAssembly`, `FuzzPluginArgs` (`dotnet`) |
| Content Patcher packs | An `Include` or `FromFile` reads a file outside the pack; a crafted `content.json`, map or image panics the scan | `framework/contentpatcher/contentpatcher.go:2000` `inside` keeps every file a pack names under its folder; `modconfig/schema.go` `Parse` reads `ConfigSchema` | `FuzzContentPack` (`framework/contentpatcher`, with a decoy pack beside it), `FuzzParse` (`modconfig`) |
| Antivirus scan of extracted mods | A malicious mod, or one a mod site's scan missed, reaches the store and then the game folder | `internal/store/scan.go:91` `checkExtracted` runs `internal/avscan` on the extracted folder inside `install`, the one place `AddArchive`, `AddArchiveKey`, `AddHashedDir` and `AddDir` (LAN receives included) pass through before the rename into the store. A detection returns a `usererr.Malware` error and the deferred cleanup deletes the extracted files; "Install anyway" is a one-shot `AllowUnscanned` behind a confirm and is recorded in the profile's history (`ChangeUnscanned`) and the download history. A scan that errors or times out (2 minutes) installs and reports a notice, and "no scanner" is silent. AMSI scans files in 32 MiB chunks, clamd gets each file as an INSTREAM; the custom command is run without a shell, never exported, and read only from the player's own settings (`antivirusCommand` and `antivirusSocket` are not portable fields, so an imported settings file cannot name a program). Loader bundles (Mortar's own downloads) are not scanned | `TestADetectionRefusesTheItemAndLeavesNothingInTheStore`, `TestInstallAnywayLetsTheItemInOnce`, `TestAScannerErrorInstallsAndIsReported`, `TestClamdProtocolFlagsOnlyTheInfectedFile`, `TestPrefsExportImportRoundTrip`; Windows EICAR acceptance: `scripts/av-smoke.ps1` |

Extraction stops at the first failure and leaves its output in a temp folder the caller discards.

## Network and links

| Surface | Threat | Guard | Test |
| --- | --- | --- | --- |
| LAN pairing | Another computer on the network pairs itself, or guesses the code | `internal/lan/pairing.go:28` states the construction: X25519 plus an HMAC proof keyed by a PBKDF2 stretch of the 8-character code, single use, five-minute life; `maxFailures` locks a peer and `burnFailures` burns the code (`:48`, `:444`); both proofs are checked with `hmac.Equal` (`:407`, `:490`); request bodies are capped (`:501`) | `TestPairing`, `TestPairingLocksOutAfterWrongCodes`, `TestPairTranscriptBindsBothNames` (`internal/lan/service_test.go`), `FuzzHandshake` |
| LAN share and store transfer | An unpaired or unlisted peer reads the store; a peer sends a tampered or different entry | Shares are MAC-proved with the pair key (`internal/lan/protocol.go:50`); a transfer token is scoped to one game and a listed key set (`internal/lan/transfer.go:399` `grantAllows`, `:338` `handleStore`); the sender vouches each entry's content hash with `entryMAC` (`internal/lan/protocol.go:70`, verified at `internal/lan/service.go:822`); the receiver hashes what it received and installs only on a match (`internal/lan/transfer.go:309`); the tar reader refuses escapes, links and special files, with entry and byte caps (`:468`) | `TestLoopbackTransfer` (unpaired share gets no grant), `TestTransferTokenScope`, `TestEntryMACBindsHashGameAndKey`, `TestExtractTarRefusesEscapesAndLinks`, `FuzzHandshake` (`/share` and both pairing steps), `FuzzExtractTar` |
| Native messaging host | A web page or another extension drives Mortar | The browser manifest allows only Mortar's extension origins (`internal/nativehost/nativehost.go:78`); a message is capped at 64 KiB (`:372`); a protocol outside the range is refused before anything runs (`:56`); a link is handed over only if it is an nxm, source or collection link (`main.go:1320`) and the app re-validates it | `TestManifestAllowsStoreOrigins`, `TestServeRefusesAnExtensionProtocolOutOfRange` (`internal/nativehost/nativehost_test.go`), `FuzzServe` (`nativehost`) |
| nxm links | A link spends another account's download key, expired or malformed, or smuggles extra fields | `internal/nxm/link.go:44` `Parse` accepts one exact shape for a known game: numeric ids, one key, three query fields, the signed-in `user_id`, not expired; `internal/nxmsvc/service.go:118`, `:156` and `:209` call it before anything is queued | `TestParse` (`internal/nxm/link_test.go`), `FuzzParse` |
| ror2mm links | A Thunderstore install link names a path instead of a package | `source/thunderstore/link.go:33` `ParseLink` accepts one shape with plain namespace, name and version parts | `FuzzParseLink` (`source/thunderstore`) |
| Nexus collections | A collection link, Nexus's revision answer or the curator's archive carries hostile choices, configs or links | `internal/sharesvc/collection.go:16` `parseCollectionURL` accepts only nexusmods.com collection pages; `internal/meta/collection.go:123` `webPage` keeps an install-yourself link only as an http or https page; `internal/sharesvc/collection_details.go:37` `readCollectionArchive` opens the 7z through `OpenSevenZip`, caps each file, keeps only FOMOD choices within the share bounds and bundled config paths `share.ValidConfigPath` accepts | `FuzzParseCollectionURL`, `FuzzCollectionArchive`, `FuzzCollectionManifest`, `FuzzBundleConfigs` (`sharesvc`), `FuzzDecodeCollection` (`meta`) |
| Links and paths handed to the system handler | A page, requirement, changelog, collection, share or catalog field carries `file://`, `steam://`, `javascript:`, a custom scheme or a UNC path, and opening it launches another app or a remote file | Every address leaves the window through `OpenWeb` (`internal/opener/opener.go` `Web`), which opens only http and https with a host, no credentials, no whitespace or control characters and at most 2048 bytes, and logs and returns an error for the rest; `openPage` (`frontend/src/mods/menu.ts`) is its only caller. The sign-in page and the queue's Nexus page go through `Web` too. `steam://validate/<digits>` is its own call, `OpenSteamValidate`, with the catalog's app id checked as digits. A folder or file open (`internal/datadir/open.go` `Open`) is only for a path Mortar builds, and `checkOpenable` refuses a relative path, a UNC path and a link to a file. A Go test fails if another file starts the handler, and a frontend test fails on `Browser.OpenURL`, `window.open` or a followed `href` | `TestWebOpensOnlyHTTPAndHTTPSWithAHost`, `TestServiceRefusesWithoutOpeningAndOpensWebAddresses`, `TestSteamValidateTakesOnlyDigits`, `TestOnlyTheGuardedCallersStartTheSystemHandler`, `FuzzWeb` (`opener`), `TestCheckOpenableRefusesWhatIsNotALocalFolderOrFile`, `TestIsUNCNamesNetworkSharesInBothSpellings` (`datadir`), `externalOpen.test.ts` |
| Multiplayer mod lists | A pasted list queues downloads from sources the host chose | `internal/packsvc/farm.go` `ParseFarm` caps size and mod count and accepts only a Stardew list; every download goes through `restoreRequest` and the download queue, the path a backup restore uses | `TestFarmListRefusesWhatIsNotOne`, `TestFarmListChecksAndFixesAGuest` (`internal/packsvc/farm_test.go`), `FuzzParseFarm` (`packsvc`) |
| Mod site answers | A Nexus, GitHub, Thunderstore, Modrinth, CurseForge or itch.io answer, or a proxy in the way, sends a body shaped to panic a read | Each answer decodes into typed structs before any field is used | `FuzzDecoders` (`nexus`, `source/nexus`, `source/github`, `source/modrinth`, `source/curseforge`, `source/itch`), `FuzzFetchReleases` (`github`), `FuzzIndexChunkDecode` (`source/thunderstore`) |
| Save files | A save from another computer or a share is shaped to panic the save scan | `internal/saves/keys.go` `distinctKeys` bounds every key it keeps (`maxKey`) and streams the file; `internal/saves/scan.go` `readInfo` reads only SaveGameInfo's top fields | `FuzzSaveFile` (`saves`; a byte-at-a-time read finds the same keys and farm) |
| mortar links and share payloads | A link or `.mortar` file imports hostile data | `internal/sharesvc/route.go:16` `parseModRoute` accepts one fixed form; `internal/share/share.go:680` `Parse` accepts only the two link prefixes or a bare payload, caps encoded and decoded size and refuses a payload whose game differs from the link's; a launch argument is only classified (`internal/sharesvc/service.go:1375` `classify`), and the import dialog previews before anything is applied; a `.mortar` file's `loader/` files must be clean text-config paths (`internal/share/loaderconfig.go` `validLoaderConfigPath`) and are written only under the receiving profile's loader config folders (`sharesvc` `writeLoaderConfigs`) | `TestParseModRoute`, `TestWrongForms`, `TestHostileShapes`, `TestCaps`, `TestReadRejects` (`internal/share/share_test.go`), `TestReceiveRoutesLinksAndFiles`, `TestLoaderConfigsRoundTripThroughAMortarFile`, `FuzzParse`, `FuzzParseDoc` (an accepted share re-encodes to itself), `FuzzReadBytes`, `FuzzReadFileEntries` (`share`), `FuzzParseModRoute` (`sharesvc`) |

## Local state and secrets

| Surface | Threat | Guard | Test |
| --- | --- | --- | --- |
| Config editor writes | An edit names a path outside the config folder, or writes a mod's manifest | `configsvc/service.go:66` `cfgPath` takes a bare `.cfg` name inside the profile's `BepInEx/config`; edits are refused while the game runs (`:202`); a shared config is applied only to a plain relative `.json` inside a folder the mod already has, never a manifest (`share/apply.go:20`, `share/file.go:95`) | `TestSetRefusesNamesOutsideTheConfigFolder` (`configsvc`), `TestApplyWritesOnlyValidConfigsInsideModFolders` (`share/apply_test.go`) |
| Diagnostics redaction | A bug report leaks an API key, account name, email or home path | `internal/support/diagnostics.go:322` `redactSettings` drops every field at any depth whose name marks a credential (`:362` `secretName`), the source account names, and rewrites the home folder to `~` (`:372`); `:412` `redactQueue` removes Nexus download keys | `TestDiagnosticsRedactsSecrets` (`internal/support/diagnostics_test.go`) |
| API keys and tokens | A key sits in a plain file that a backup, share or diagnostics bundle carries | `internal/secret/secret.go` stores credentials in the OS keyring only; `internal/nexussvc/apikey.go:42` keeps the Nexus key there, `internal/nexussso/oauth.go:193` the OAuth grant, `internal/source/itch/service.go:45` the itch.io key; settings keep the account's display name only | `TestSignInOutKeepsKeyOutOfSettings` (`internal/nexussvc/service_test.go`) |
| Tests touching real data | A test run reads or rewrites the developer's own data folder | `datadir` refuses a non-temporary data folder under `go test` | `TestTestsCannotReachRealData` (`internal/datadir/guard_test.go`) |

## Out of scope

A malicious mod's own code runs inside the game with the user's rights; Mortar installs it where the loader expects it and does not sandbox the game. Mortar does not verify Nexus or Thunderstore content beyond the archive checks above.
