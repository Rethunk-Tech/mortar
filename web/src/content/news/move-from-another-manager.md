You don't have to start over to try Mortar. It reads the profiles your current manager already has.

## Import a profile

Open the Profiles page and choose **Import…**. Mortar lists the profiles it finds for the game from r2modman, Gale, Vortex, Mod Organizer 2 and Stardrop, each with a preview. Pick one, and Mortar shows what it holds, then installs or queues what is missing.

The other manager's profiles are left as they were, so you can keep using it while you decide.

## Several at once

**Import…** can also read every r2modman or Gale profile in a data folder you choose, in one step.

## Codes and .r2z files

For a Thunderstore game, **Use a code or file…** reads an r2modman or Gale profile code or an `.r2z` file.

## Vortex

Mods Vortex linked into the game folder are copied, not moved, so Vortex keeps working. A Nexus Collection link opens in Mortar like a shared profile.

## Mods with no page

A copied mod may have no page to update from. Group the Mods list by **Source** and choose **Find sources**: Stardew mods on Nexus, BepInEx plugins on Thunderstore, Vintage Story mods on the Mod DB. You can also right-click a mod and choose **Set Nexus page…**.
