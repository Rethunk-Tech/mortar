A Mortar profile is one set of mods. When a friend needs the same set, you don't send them a list to rebuild by hand. You send the profile.

## Copy a link

Open the profile's menu, choose **Share profile**, then **Copy link**. The link names every mod and its Nexus or GitHub file, with pins, groups and why each mod is there.

Your friend opens the link at `mortar.rethunk.tech/<game>/p`, sees the mod list, and imports it into Mortar in one click. The whole profile is inside the link, after the `#`, so it never reaches a server.

## Or save a file

For a large profile, save a `.mortar` file instead. It also carries the profile's settings and notes. Your friend opens it with **Import › From a link or file…**.

## Playing together

Before a multiplayer session, the host opens the profile menu and chooses **Multiplayer mod list…**. It copies the switched-on mods with their versions and sources. Each friend pastes it under **The host's list** and presses **Check**: missing mods show **Install**, other versions show **Update**, and **Fix all** queues every one.

This works for Stardew Valley, Vintage Story and Thunderstore games such as Lethal Company, R.E.P.O., PEAK, Content Warning and Valheim. Many mods refuse a player on another version, so match before joining.

## Thunderstore games

For a Thunderstore game, **Save .r2z…** writes a profile file r2modman and Gale can open, without posting a public code.
