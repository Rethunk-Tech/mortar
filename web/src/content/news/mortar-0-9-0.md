Mortar now sets up Cyberpunk 2077 mods. Each download goes where the game wants it, whether it's Cyber Engine Tweaks, RED4ext, redscript, a REDmod or a plain archive, following the same rules Vortex uses. Archive mods load in your profile's order, REDmods compile before the game starts, and the game always starts modded.

An archive mod can become a REDmod from its menu, and go back. The Tools menu runs the game's own tools with your profile: REDLauncher, REDmod deploy and CyberCAT.

When a download has a layout Mortar doesn't recognise, it shows you the files and asks before installing them as packed. It also asks before installing an old core mod or files that would overwrite the game's config.

This release also fixes missing requirements in games other than Stardew Valley, which could name an unrelated Stardew Valley mod. Mods added under those names get their own names back.
